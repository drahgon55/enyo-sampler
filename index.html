Enyo 2.7 sampler

Every sample the three libraries used to ship, ported to native ES modules. No bundler, no build step.

enyo 33 samples The framework itself: controls and inputs, repeaters and data lists, scrollers, popups, drag and gesture, audio and video, animation, Ajax and web services. layout 23 samples Arranging things: Panels and the seven arrangers, Fittables, the List family, Slideable, ImageView and PanZoomView. onyx 22 samples The widget set: buttons, checkboxes and toggles, inputs, menus and submenus, pickers, popups, toolbars, sliders, tooltips.

These are ports, not the originals. They come from the 2.5.1-release tag of enyojs/enyo, enyojs/layout and enyojs/onyx — the last tag that still had them, before 2.6 deleted every samples/ folder. Each library's own samples/README.md records what its port changed and what it found broken along the way.

Serve the directory that holds the checkouts, not any one of them. The pages resolve bare specifiers through an import map, so enyo, layout, onyx, enyo-ilib and this repo all have to sit side by side under the served root: 

python3 layout/test-layout/serve.py 8000 /path/that/holds/the/checkouts

Use that rather than python3 -m http.server: the latter lets the browser cache ES modules, so a reload can silently re-run stale code.
